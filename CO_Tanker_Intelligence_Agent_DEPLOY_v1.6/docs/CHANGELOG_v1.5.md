# CO Tanker Intelligence v1.5 · 18 November 2026

## Added
- **Always-On Watch** in desktop Chrome and Samsung PWA; source health and freshness dashboard.
- Independent Python public-source collector with configurable, hardcoded trusted sources, safe URL validation, bounded downloads, deduplication and error reporting.
- GitHub Actions scheduled workflow (every 3 hours, best-effort) to update public static JSON; GitHub Pages PWA integration.
- **Dynamic guided study prompts** created from newly discovered links; explicitly not legal interpretations or auto-approved safety procedures.
- Feed URL configuration with Chrome optional host permission; local cached snapshot and marks reviewed.
- New Watch preferences in backup export/import. Previous user data format preserved.
- Network-first service-worker handling for scheduled feed JSON, while static app assets remain cached offline.

## Retained
- Existing PSC/SIRE 2.0/CDI-M inspection checklists, CO Academy, practice simulator, port planner, existing local news reader, notes and backup.

## Not yet included
- No actual GitHub repo or hosted scheduler is deployed by this ZIP alone.
- No automated full-PDF comparison, legally verified entry-into-force tracking, AI generation of detailed lessons, server notifications or cross-device account-based sync.
- Live success for third-party sites could not be guaranteed from this test environment; failures remain visible.
