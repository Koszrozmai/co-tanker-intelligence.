# Known issues and limitations
- No automatic cloud sync between Chrome and Samsung. Use a JSON export/import backup.
- No automatic full-text regulatory PDF interpretation or guaranteed live access to protected websites.
- Mobile background alerts depend on host/browser; task reminders are available in app.
- No safe AI-assisted QMS form transfer until actual templates are provided and inspected.
- Service worker PWA installation requires HTTPS hosting; single-file HTML can be run offline but local-storage behavior differs by browser.
