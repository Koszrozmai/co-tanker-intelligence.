CO Tanker Intelligence Samsung Android v1.2

PWA: Serve via HTTPS. Install from Chrome (three dots > Add to Home screen / Install app).
Offline content: 64 PSC, SIRE 2.0 and CDI self-checks; 12 lessons; 5 routines; local notes.
News feeds: cross-origin listing sites generally require server-side same-origin relay.
A constrained Netlify Function is provided for nine preset sources. Deploy from Git
or the CLI with Functions support, NOT static drag-and-drop only.
No background fetch is guaranteed when Android suspends the PWA.
Export/import JSON for backup and manual transfer between desktop and mobile.
Custom RSS sources are direct CORS fetch only and may fail even with relay.
